> 封面图仿色自我最喜欢的大师：Monaris 👍 👍 👍

# 基础
- 影调：明暗（高、中、低）+反差（硬、软）+色彩（单色、冷调、暖调、冷暖对冲）+灰阶（长、中、短）
- 解开面部太黑：人物蒙版提曝光，提阴影，减高光和白色
- 青橙色调：三原色右右左
- 直方图：左边是阴影，如果红色很高说明大部分红色都是暗红色，也就是说画面正常亮度下缺少红色，也就是说偏红色的对比色青色！右边相反，什么颜色很高说明画面偏什么颜色！
# 滨田英明（日系胶片）
纯净温柔风格，宾得中画幅胶片67（高光宽容度佳可以过曝），低饱和清新
两类：
1. 柯达暖黄：
* 影调：中高调，长调，软硬都有，最暗阴影缺失细节
* 色调：中间调暖黄，阴影青蓝，肤色红润
1. 富士青绿：
* 影调：中高调，长调，软为主，最暗阴影缺失细节
* 色调：中间调青绿，阴影青蓝，肤色冷白
* 质感都是胶片感，粗糙
影调：
* 拉高曝光成软高调，阴影拉到最低黑色色阶拉到最大，高光和白色色阶都下降
* 曲线左边往上右拉（减少最暗部细节），右边往下左拉（防止过曝）
* 明亮度范围蒙版进一步提高高光阴影对比度
色调：
* 色温不变色调偏绿（负值）
* hsl红色偏橙低饱和，橙色偏黄高饱和和亮度，黄色高亮，绿色大偏青，青色小偏蓝提亮，蓝色小偏青提亮
* 局部染色：阴影青蓝（220、13），中间调（53、12），中间调提亮进一步通透，高光（208、5），平衡全部给阴影，混合100%让青蓝色附着更强
* 三原色：绿小偏青
质感：
* 纹理降低
* 效果提高颗粒和粗糙度
* 锐化40蒙版25，明亮度5颜色25
# 品川力（日系暗调、青橙变体）
日系低饱和暗调风
* 影调：低调，长调或中调，硬，最暗阴影稍微缺失细节，高光缺失大量细节
* 色调：中间调品红，高光琥珀绿，阴影青蓝，低饱和褪色感，蓝偏青，红偏橙
* 质感：低清晰
影调：
* 曝光曲线提高阴影，拉低高光，区域曲线降低高光、暗色调微提亮色调，曝光那里提升阴影和黑色色阶100恢复部分细节，降低高光和白色色阶消除高光细节
* 最后微调曝光
色调：
* 三个颜色通道曲线拉对比，红色高光偏青
* hsl蓝色偏青大低饱和，青偏蓝低饱和高亮，绿偏黄大低饱和高亮，黄偏橙大低饱和，橙低饱和褪色感，红偏橙低饱和，整体把照片整褪色
* 颜色分级：阴影青蓝（156、40），中间调品红（335、32），高光琥珀绿（100、7），混合平衡都到100
* 三原色：青橙色调
* 白平衡色调偏暖
质感：
* 清晰度降低
* 去朦胧提高
* 锐化
# Tomasaki（日系动漫）
日系新海诚动漫风
* 影调：高调，长调或中调，最暗阴影稍微缺失细节，阴影缺失大量细节
* 色调：蓝偏青，绿偏青，蓝绿高饱和
* 质感：高纹理、线条感、低清晰
影调：
* 曲线提高阴影
* 曝光拉高曝光，降低高光提高白色，提高阴影和黑色
* 
色调：
* 拉高自然饱和度（鲜艳度）
* hsl黄偏绿低亮，绿偏青低饱和低亮，蓝高饱和提亮，
* 蒙版天空色温偏冷，色调偏绿
质感：
* 加纹理
* 减清晰
* 加去除薄雾
* 可以使用一晨老师的滤镜库技巧
# Michale Kagerer（森系、青橙变体）
* 影调：低调，长调，阴影不是全黑有细节，有蒙版加强明暗对比
* 色调：暖调，主要是橙黄绿，阴影偏青蓝，高光偏黄绿或橙黄，饱和度中等，冷色饱和偏低，暖色饱和偏高
* 质感：柔和、朦胧
影调：
* 曲线提高阴影，压暗高光，压暗暗部，同样处理在三个颜色通道上
* 回基本面板提高曝光，降高光，微加阴影，加黑色白色，
* 区域曲线降低亮色调和阴影
色调：
- hsl：绿偏黄降饱和提亮，黄色降饱和提亮，橙色偏红提饱和提亮，红色偏橙提亮，青偏蓝降饱和提亮，蓝偏青降饱和，个人：紫偏洋红降饱和提亮，洋红降饱和提亮
- 提高自然饱和度到60
- 颜色分级：阴影青蓝（202，50）、高光黄绿（82、6），混合平衡都给100偏高光
- 蒙版：对角建立线性蒙版，上面亮下面暗
- 三原色：偏青偏黄
质感：
- 降清晰度
- 锐化降噪
- 提高去薄雾
# Liam Wong（赛博朋克）
场景大都是雨夜，常使用慢快门（不用三脚架铁臂阿童木）
- 影调：低调，长调，软调，阴影细节丰富黑色较多，四周暗中心亮
- 色调：冷调，主色调蓝色紫色品红，高饱和
- 质感：柔和、朦胧、晕影
影调：
- 降曝光加阴影，降黑色让暗部足够黑，降对比度增加柔和感，
色调：
- 三原色：蓝色大高饱和
- 色温蓝，色调品红
- hsl蓝色偏青大低饱和高亮，橙黄高亮
- 颜色分级，阴影加蓝紫高饱和，中间调加紫低饱和，高光蓝色低饱和
质感：
- 降纹理
- 降清晰度
- 加晕影，中点偏左
- 地面蒙版多降纹理
# Sam Alive（原色胶片）
日出日落，35、50镜头，7分身全景远景
- 影调：低调，硬调，暗部有细节，高光不溢出，缺失黑色和白色部分
- 色调：青橙微微突出，保留原有颜色，暗部青蓝或蓝紫，肤色橙红，青橙色饱和度对立
- 质感：锐化、颗粒
影调：
- 曲线黑色左移上移，压暗暗部，中间调回正，高光提高，白色降低
- 红色通道s曲线，复制到其他通道，蓝色通道白色降低
- 高光白色降低、阴影黑色提亮
- 对人物降低饱和
色调：
- hsl红色降饱和，橙色偏红降饱和低亮，黄色偏绿降饱和高亮，绿色偏青，蓝色偏青微微降饱和
- 颜色分级，高光加青低饱和，阴影加蓝紫中饱和，混合平衡右边拉满
- 拉蒙版微调整去除过多的青蓝色
质感：
- 加锐化
- 加颗粒
# Ben Thomas（糖果卡通）
必须正午太阳最大的时候去有大色块的地方拍
- 影调：高调，软调
- 色调：主次分明，主色调高饱和度，辅助色适中或低饱和度，分层调整饱和营造空间层次
- 质感：薄雾、朦胧
影调：
- 曲线反s曲线
- 降低对比，降高光（拉底）白色，提阴影黑色
色调：
- 三原色蓝色偏青饱和拉满
- hsl橙偏黄，黄偏橙，绿偏青，蓝偏青，根据需要调整饱和度，饱和度高了一般亮度也要提高
质感：
- 减清晰度
- 加朦胧
# 森山大道（野性黑白）
真正的艺术从不需要被所有人理解，纯粹的构图和怪异有冲击力的画面给人以直击心灵的震撼
- 影调：极致硬调，长中短调都有，纯黑纯白少量的灰
- 色调：黑白
- 质感：粗糙模糊
影调：
- 黑色右移白色左移，s曲线
- 对比拉满，高光拉底，升高白色，黑色拉底
- 蒙版亮度范围最亮处降低曝光和高光，局部径向或线性降曝光
色调：
- 转黑白，色温偏左
质感：
- 降纹理
- 降清晰度
- 加薄雾
- 加颗粒，大粗颗粒
- 加镜头模糊，模糊度不高
构图：
- 不水平有晃动感
- 局部剪裁
题材、手法：
- 街头、小巷、老城区房子中间、广告牌、废弃的东西、水雾玻璃、有特色的车、车站、破碎玻璃、特色人群团体、人流、抓拍特别的人、泛黄海报
- 喜欢引导线构图、中心构图、建筑线条感明显
- 人物和光影结合
- 他的晃动感我感觉是故意的因为调正了以后反而造成了画面的不平衡
# Monaris（青橙电影）
街头摄影，利用玻璃、水面，将虚影、倒影与现实交汇，
- 影调：低调，中长调，软调，黑色白色缺失，暗部细节丰富，缺少高光中间调
- 色调：青橙，低饱和，阴影饱和偏高，阴影蓝紫，中间青蓝，高光黄绿
- 质感：锐利、薄雾
影调：
- 曲线：提亮黑色，大幅压低白色，
- 基础：大降高光、阴影，降低黑色，提升白色，降对比
色调：
- 色温冷，加自然饱和度
- 三原色青橙色调，蓝色大高饱和
- 蓝色通道白色下拉
- 颜色分级阴影蓝紫（255、16），中间调青蓝（190、34），高光黄绿（70、5），混合拉满平衡偏高光
- 蒙版选择地面，色温变暖
质感：
- 加薄雾
- 加大锐化
